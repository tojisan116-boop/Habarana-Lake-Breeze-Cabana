# Habarana Lake Breeze Cabana Website

Premium mobile-first hospitality website for Habarana Lake Breeze Cabana, Habarana, Sri Lanka.

## Features

- Mobile-first responsive design
- Tablet / laptop / desktop layouts
- English + Sinhala language switcher
- Persistent language preference
- Premium hospitality styling
- Real property photographs
- Room showcase
- Room detail modal
- Responsive gallery
- Image lightbox
- WhatsApp enquiry system
- Click-to-call phone number
- Booking.com link
- Google Maps integration
- Mobile sticky contact bar
- Accessibility basics
- Reduced-motion support
- SEO metadata
- Open Graph metadata
- Lazy-loaded images
- No fake availability
- No fake reviews
- No API keys
- No database
- No exposed secrets

## Deployment

This website can be hosted using GitHub Pages.

1. Create a GitHub repository.
2. Upload index.html.
3. Upload style.css.
4. Upload script.js.
5. Create the images folder.
6. Upload all photographs.
7. Open repository Settings.
8. Open Pages.
9. Select the main branch.
10. Save.

## Important

Before publishing:

- Replace YOUR-DOMAIN.com in index.html.
- Verify the Google Maps location.
- Verify the Booking.com URL.
- Verify all property information.
- Add an official email address if one becomes available.
- Add official social media links if required.
- Compress photographs before uploading.
